# 代码项目库 (Code Projects Library)

这个目录用于存储和组织我编写或寄存的各种代码项目。

## 项目结构

每个项目应包含：
- 源代码文件
- README.md - 项目简介和使用说明
- 示例或演示（如适用）

## 项目列表

项目将在下方列出，每个项目都有简短的描述：

### 示例项目结构
```
code-projects/
├── project-name/
│   ├── README.md
│   ├── src/
│   └── examples/
```

## 添加新项目

1. 在 `code-projects` 目录下创建新的项目文件夹
2. 添加项目代码和 README.md
3. 在此文件和网站的 Portfolio 组件中更新项目列表
